Beginner Guide & Setup Instructions

How to run CaptionGenius on Windows:

  1. Instant Run (Zero installs required): Simply find the index.html file in the folder and double-click it. It will open immediately in Microsoft Edge, Google Chrome, or your favorite browser!
  2. Using VS Code Live Server (Recommended for developers): Open the folder in VS Code, install the "Live Server" extension, right click index.html and click "Open with Live Server".
  3. Optional Node.js Backend: If you have Node.js installed and want a secure server, open PowerShell, run npm install then npm start to launch at http://localhost:3000.

How to install on iPhone & Android as a PWA:

  1. On iPhone / iPad (iOS Safari):

    1. Open your published website link in Safari (must be Safari for iOS PWA installation).

    2. Tap the Share button at the bottom of the screen (square with upward arrow).

    3. Scroll down and tap "Add to Home Screen".

    4. Tap "Add" in the top-right corner. The CaptionGenius icon will appear right on your iPhone home screen, working just like a native App store app!

  2. On Android (Google Chrome):

    1. Open the site in Chrome.

    2. Tap the "Install" button in our navigation bar or tap the three dots menu (⋮) -> "Install App".

How to publish this website 100% Free:

Method A: Netlify Drop (Fastest - 30 seconds):

Go to app.netlify.com/drop, drag and drop this entire project folder into the browser window, and you will get a live https://your-app.netlify.app URL instantly for free.

Method B: Vercel:

Upload this folder to GitHub, go to Vercel.com, import the repo, and click Deploy. It includes automated HTTPS and fast global CDN.

Method C: GitHub Pages:

Push to a GitHub repository, go to Settings -> Pages -> Deploy from branch "main" -> save. Live in 1 minute.
